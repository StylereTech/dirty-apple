# Approved Replit design

Original approved source exported from Dirty Apple Website on 2026-10-29.
Published reference: https://dirty-apple-website.replit.app
Replit project: https://replit.com/replid/0166d801-d4d8-425a-ae93-316b368b222e

The deployable Next.js adaptation is in frontend/src/components/Atelier.tsx
and frontend/src/app/atelier.css. It retains the existing catalog API,
product details, cart, checkout, administration and other collection routes.
Original images and supplemental artwork are in frontend/public.
The reference source uses Wouter/React, Lucide and Tailwind 4; the production
adaptation uses the existing Next.js router and Tailwind 3 project.
No inventory or prices are hardcoded in the production adaptation.
